# macOS: уровни сложности и балансные опции

Это дополнение к [профилям графики](../macos-graphics/README.md). Здесь
собраны **только опции, меняющие баланс**, разложенные по уровням: от
безопасного «Vanilla+» до хардкора. QoL-настройки (финансы на карте,
подсказки, автосохранение и т.д.) и графика этими профилями **не меняются**.

Профили проверены на **MacBook Air M4, 24 ГБ, macOS 26**.

## Уровни

| Уровень | Что включает | Кому |
|---|---|---|
| `level0-vanilla` | Все балансные изменения выключены | Точка отсчёта / откат |
| `level1-vanilla-plus` | `battleExplosionHeight=3`, `fieldPromotions=true` | Рекомендуемый старт |
| `level2-logistics` | Level 1 + `storageLimitsEnforced=true`, `canSellLiveAliens=true` | Второе прохождение, управление базой |
| `level3-hardcore` | Level 2 + `aggressiveRetaliation=true`, `battleUFOExtenderAccuracy=true`, `sneakyAI=true` | Опытным, по одной опции |

### Level 1 — Vanilla+

- **Высота взрыва = 3** — объёмные взрывы: гранаты и ракеты задевают
  несколько уровней. Больше тактики, меньше «плоских» взрывов.
- **Боевые повышения** — повышение получают только бойцы, которые реально
  были на задании. Логичнее для отыгрыша, без сильного влияния на баланс.

Это безопасный способ сделать бои интереснее, не превращая игру в XCOM 2012.

### Level 2 — Logistics

Добавляет к Level 1:

- **Лимиты складов для найденных предметов** — изоляторы и склады реально
  ограничены; приходится следить за местом.
- **Продажа живых пришельцев** — можно продавать живых alien'ов, чтобы
  освободить изоляторы. В описании игры рекомендуется вместе с лимитами.

Это старая школа управления базой, но может быть утомно, если не любишь
микроменеджмент.

### Level 3 — Hardcore

Добавляет к Level 2:

- **Агрессивное возмездие** — НЛО активно ищут вашу базу, чаще базовые штурмы.
- **Точность выстрела, как в UFO Extender** — точность падает с дистанцией,
  показывается шанс попадания. Тактичнее, но это не ваниль.
- **Скрытный ИИ** — ИИ старается действовать скрытно, засады и обходы.

Не включай всё сразу на первом прохождении: комбинация может быть очень
жёсткой.

## Применение

Игра должна быть **закрыта** — при выходе она сохраняет `options.cfg`.

```sh
# список уровней
./scripts/apply-gameplay-profile.sh --list

# применить уровень
./scripts/apply-gameplay-profile.sh level1-vanilla-plus

# применить и запустить установленную игру
./scripts/apply-gameplay-profile.sh level2-logistics --launch

# посмотреть состав профиля
./scripts/apply-gameplay-profile.sh --show level3-hardcore

# откатить баланс к ванили
./scripts/apply-gameplay-profile.sh level0-vanilla
```

Скрипт:

- меняет только перечисленные в профиле ключи;
- создаёт резервную копию `options.cfg.bak-*`;
- проверяет, что игра не запущена;
- `--launch` открывает `/Applications/OpenXcom.app`, иначе `dist/OpenXcom.app`.

Каждый профиль задаёт **весь набор балансных ключей**, поэтому переход
`level3 → level1` не оставит включёнными лишние опции.

## Добавлять сложность постепенно

1. Начать с `level1-vanilla-plus`.
2. После первого прохождения применить `level2-logistics`.
3. Для хардкора — `level3-hardcore`.
4. Если какая-то опция не нравится, её можно выключить вручную в
   **Настройки → Дополнительно**; профиль при следующем применении вернёт
   свой набор.

## Что не входит в уровни

Эти опции **не включаются** ни в один профиль, потому что меняют дух
оригинала или являются читами:

- **Самоуничтожение оружия пришельцев** — «как в XCOM 2012»;
- **Оставлять допрошенных пришельцев** — XCOM 2012;
- **Позволить развивать псионическую силу** — новая прогрессия;
- **Разрешить пси-захват** — меняет условие победы;
- **Мгновенные гранаты** — другой тайминг взрывов;
- **Альтернативные способы движения** — новая механика;
- **Читерство с сохранениями** — анти-сейвскам, не старый XCOM;
- **Форсированный запуск ТС** — чит;
- **Свободный дизайн первой базы** — удобство, но не ваниль. У тебя он
  сейчас включён; профили его не трогают.

**Пришельцы истекают кровью** — спорная опция «на любителя»; тоже не входит
в уровни, включай вручную, если хочешь реализм.

## Сложность и Ironman

Уровни выше меняют правила, но **сложность** выбирается при **Новой игре**:

- **Veteran** — классический уровень;
- **Genius / Superhuman** — если хочется жёстче;
- **Ironman** — только если готов к отсутствию обычных сохранений.

## Где менять вручную

- **Настройки → Дополнительно** — все балансные переключатели;
- числовые значения (`Высота взрыва`) меняются левым/правым кликом;
- **Настройки → Геоскейп** и **Поле боя** — скорости, скроллинг, QoL;
- **Настройки → Видео** — графика.
